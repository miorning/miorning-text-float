喵咛文本窗 全局设置

所有网页，一个开关

点击文本框放大编辑，拖动小喵图标可吸附到屏幕四周。

全局启用

正在读取设置…

默认在所有普通 HTTP / HTTPS 网页开启。暂停或恢复会同步到已打开和之后新开的网页；暂停时，小喵图标会变淡，仍可点击恢复。

浏览器内部页、扩展商店等受保护页面不允许注入。更新插件后请刷新原有网页；浏览器的站点访问限制仍会生效。

全局开关快捷键

点击录入后，按下新的组合键即可保存；Esc 取消。请使用 Alt、Ctrl 或 ⌘ 搭配字母、数字或 F1–F12。在普通网页获得焦点时触发，一次切换所有网页；不是系统全局热键。系统及浏览器已占用的组合可能无法触发。

本地文本缓存

正在统计…

按网站勾选，清空本插件保存的版本与草稿。全局开关、快捷键、图标位置与窗口偏好会保留。平台作品、登录状态和网站本身的缓存不会清理。

正在读取缓存…

大小按保存记录的键名与内容以 UTF-8 JSON 字节统计，不包含浏览器数据库的磁盘开销。清空后，已打开的对应文本窗会关闭，网页当前文字保留；再次打开时会重新建立版本。

通用网站支持普通文本框与可编辑文本区域。图片 @ 引用仍需网站原生支持，平台更新可能影响适配。
文本版本与设置保存在本机浏览器扩展中，不上传提示词。
